# boutiqueDouglass
Boutique Douglass

A responsive front-end web project for Boutique Douglass, an online women's fashion store featuring seasonal dress collections, a size guide table, and order processing workflows.

Initially created as a coursework assignment for Web Development; moved here for version control and GitHub submission.

Getting Started

These instructions will give you a copy of the project up and running on your local machine for development and testing purposes. See deployment for notes on deploying the project on a live system for evaluation.

Prerequisites

Requirements for the software and tools to inspect, test, and push the project:

Web Browser: Google Chrome, Mozilla Firefox, Microsoft Edge, or Safari.

Code Editor: Visual Studio Code (recommended).

VS Code Extension: W3C Offline HTML Validator (for local compliance testing).

Git & GitHub Client: For cloning and pushing code to the default main branch.

#Installing

A step-by-step series of examples that tell you how to get a development environment running:

Clone the repository from GitHub:

git clone https://github.com/your-username/boutique-douglass.git


Navigate into the project directory:

cd boutique-douglass


Format document formatting in Visual Studio Code:
Ensure tab indentation is strictly set to 4 spaces using Shift + Alt + F (Format Document).

Launch the application:
Open index.html directly in your browser or launch it using VS Code Live Server.

Verify developer naming conventions:
Confirm that all developer-facing code (id, class, comments, filenames) uses English kebab-case, while user-facing text is displayed in Spanish.

#Running the tests

Explain how to run the automated tests and code checks for this project.

Sample Tests

Tests check for standard HTML5 validation and strict adherence to W3C standards:

Open index.html in Visual Studio Code.

Run the W3C Offline HTML Validator plugin.

Verify that zero syntax errors or structural warnings are reported.

#Style test

Checks if best practices and the required coding style guidelines have been followed:

Semantic Tags Check: Ensures layout uses <header>, <nav>, <main>, <section>, <article>, <aside>, and <footer> rather than non-semantic <div> elements.

Naming Conventions Check: Checks that IDs and classes (e.g., clothing-and-dresses-card-container, site-header) use lowercase kebab-case in English.

Viewport & Responsiveness Test: Inspects Media Queries across 3 device width ranges (<768px, 768px–991px, and ≥992px).

#Deployment

To deploy this project for grading:

Commit all final changes to your local Git repository.

Push your final code to the default main branch on GitHub:

git push origin main


Ensure the README.md file appears on the main repository view.

Provide the URL of your main branch for evaluation before the deadline.
