# Boutique Douglass

A responsive web application for a low-cost women's clothing boutique built with semantic HTML5 and CSS3.

## Getting Started

To view the project locally:

1. Clone the repository:
   ```bash
   git clone [https://github.com/your-username/boutique-douglass.git](https://github.com/your-username/boutique-douglass.git)
   ```

## Built With

HTML5 (Semantic elements: header, nav, main, section, article, aside, footer, table)

CSS3 (Flexbox grid layout, hover effects, Media Queries for desktop, tablet, and mobile)

Google Fonts (Material Symbols Outlined icons)
